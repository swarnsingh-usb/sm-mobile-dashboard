# Spend Management Mobile Dashboard

The dashboard uses the name **Spend Management Mobile Dashboard** in its browser title, header and footer.

The U.S. Bank logo is bundled locally as `static/usbank-logo.svg`, copied without changing its paths or colors from the app's `src/branding/usbank/assets/images/logo-usb.svg`. It does not need an external image host.

The interface palette comes from `src/branding/usbank/styles/Theme.ts` in the mobile app:

- Primary blue: `#0A41C5` for buttons, links and focus indicators.
- Navy: `#0C2074` for headings and labels.
- Red: `#D11B25` for the header accent.
- Light surfaces: `#F3F8FB` and `#EEF6FF`.

Build status colors retain distinct success/failure meanings. The logo retains its own original colors. Branding applies to the web interface; existing repository coordinates, pipeline markers and installation commands retain their operational identifiers.
